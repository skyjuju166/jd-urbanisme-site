## ÉTAPE 1 — Lire le contexte existant

---

## ÉTAPE 2 — Rechercher l'actualité récente

Effectue des recherches web sur les 5 thèmes prioritaires. Pour chaque thème, cherche des actualités des 8 dernières semaines NON encore couvertes sur le site :

1. **Jurisprudences PLU** — décisions Conseil d'État ou CAA sur PLU, zonage, modification, révision, légalité des règlements de zone
2. **RLP / RLPi** — jurisprudences sur les règlements locaux de publicité, enseignes, publicité extérieure
3. **PDA / ABF** — périmètre des abords, avis ABF (Architecte des Bâtiments de France), contentieux permis en secteur protégé
4. **CERFA** — nouveaux formulaires officiels ou formulaires mis à jour (permis de construire, déclaration préalable, enseigne…)
5. **Code de l'urbanisme** — décrets, ordonnances, lois modifiant le Code de l'urbanisme ; nouvelles procédures

Recherches suggérées :
- "Conseil d'État urbanisme [mois] [année] site:legifrance.gouv.fr OR site:conseil-etat.fr"
- "décret urbanisme [mois] [année] site:legifrance.gouv.fr"
- "CERFA permis construire nouveau formulaire [année]"
- "jurisprudence PLU [mois] [année]"
- "RLP RLPi annulation tribunal administratif [année]"
- "ABF permis de construire Conseil d'État [année]"

## ÉTAPE 3 — Sélectionner 1 ou 2 sujets

Sélectionne les sujets les plus pertinents parmi les thèmes non encore couverts depuis 6 semaines. Priorité :

- Nouvelles lois ou décrets impactants
- Jurisprudences récentes avec apport jurisprudentiel clair

## ÉTAPE 5 — Mettre à jour actualites.html

Lis `site/actualites.html`. Pour chaque nouvel article :

1. **Bloc featured** : remplace le bloc `<div class="featured-article">` par le premier nouvel article (label "✨ Nouveau — [date longue]", 4 points clés).

2. **Cartes dans la grille** : ajoute les nouvelles cartes en HAUT de la grille `.articles-grid`. Format :
```html
<article class="article-card">
  <div class="card-tag">[CATÉGORIE]</div>
  <h3><a href="/[NOM-FICHIER].html">[TITRE]</a></h3>
  <p>[RÉSUMÉ 2-3 phrases]</p>
  <div class="card-meta">
    <span>[DATE LONGUE]</span>
    <span>[X min]</span>
  </div>
  <a href="/[NOM-FICHIER].html" class="card-link">Lire l'article →</a>
</article>
```

3. **JSON-LD CollectionPage** : dans le script JSON-LD de type `CollectionPage`, ajoute les nouveaux articles en tête du tableau `mainEntity`, en décalant les existants. Format :
```json
{
  "@type": "Article",
  "headline": "[TITRE]",
  "url": "https://juliendallemagne.fr/[NOM-FICHIER]",
  "datePublished": "DATE_DU_JOUR"
}
```
